# /publish — 一键发布流程

将学城文章从搬运到排版配图全流程自动完成，推送到公众号草稿箱，等待人工预览后发布。

## 用法

```
/publish {学城文章链接或目录链接}
```

示例：
- `/publish https://km.sankuai.com/collabpage/1234567890`（单篇）
- `/publish https://km.sankuai.com/collabpage/1234567890 最新3篇`（目录，拉最新3篇）

## 执行步骤

按以下顺序串行执行，每步完成后输出进度，任一步失败立即停止并报告原因。

### 阶段一：Agent A — 搬运

读取 `wiki-fetcher/AGENT.md`，执行完整搬运流程：
1. 从学城读取文章内容
2. 转换为公众号兼容 HTML
3. 推送到草稿箱，获取 `media_id`

输出：
```
📦 [1/2] 搬运完成
文章：《{标题}》
media_id：{media_id}
```

### 阶段二：Agent B — 排版配图

读取 `layout-optimizer/AGENT.md`，以阶段一的 `media_id` 为输入，执行完整排版配图流程：
1. 读取草稿 + 检索历史经验
2. 分析文章类型，确定封面图模板和正文配图方案
3. 排版优化
4. 生成封面图（模板渲染）
5. 正文配图（双图对比组，如需要）
6. 回写草稿箱

输出：
```
🎨 [2/2] 排版配图完成
封面图：{模板名}
正文配图：{n}张 / 未放图
```

### 完成汇报

```
✅ /publish 完成

文章：《{标题}》
类型：{文章类型}
草稿 media_id：{media_id}

封面图：{模板名} 模板生成
正文配图：{n}张双图对比组（位置：{段落标识}）/ 未放图

👉 请前往公众号后台预览草稿
   - 确认封面图效果
   - 每个配图位置选留一张图，删除另一张
   - 确认无误后点击发布
```

## 多篇模式

如果是目录模式且拉取多篇，对每篇依次执行阶段一 + 阶段二，全部完成后汇总报告：

```
✅ /publish 完成（共 {n} 篇）

1. 《{标题1}》media_id: {id1} — 封面图: {模板} | 配图: {n}张
2. 《{标题2}》media_id: {id2} — 封面图: {模板} | 配图: {n}张
...

👉 请前往公众号后台逐篇预览后发布
```

## 错误处理

| 阶段 | 错误 | 处理 |
|------|------|------|
| 阶段一 | 学城无权限 | 停止，报告"无权限读取该文档" |
| 阶段一 | 草稿推送失败 | 停止，保留转换后 HTML |
| 阶段二 | Playwright 未安装 | 跳过封面图生成，其余继续 |
| 阶段二 | 图片上传失败 | 标注"待手动替换"，继续回写 |
| 阶段二 | 回写失败 | 保留优化后 HTML 在对话中 |
