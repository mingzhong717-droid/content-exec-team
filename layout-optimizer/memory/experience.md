# 排版经验库

> 每次完成排版任务后，将决策和效果记录在此。
> 下次处理同类文章时，优先检索本文件。

---

## 使用说明

每条记录格式如下：

```
## {日期} | {文章标题} | {文章类型：技术/故事/资讯/观点/其他}
- 决策：{具体做了什么排版调整}
- 原因：{为什么这样处理}
- 效果：待反馈 / 好 / 差 / {用户具体反馈}
```

效果标记说明：
- `待反馈`：用户尚未给出评价
- `好`：用户认可，下次同类文章可复用
- `差`：用户否定，下次同类文章避免
- 具体文字：用户的原话反馈，优先参考
